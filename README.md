# DataLens

DataLens is a modular Python desktop application designed for data cleaning, exploratory data analysis, data transformation, and visualization.

It allows users to explore and process their own datasets through a user-friendly graphical interface without writing code.

## Features

- CSV, Excel, and JSON file support
- Missing value detection and handling
- Duplicate detection and removal
- Data type conversion
- Outlier detection
- Calculated columns and data transformation
- Dataset merging and concatenation
- Descriptive statistics and correlation analysis
- Data visualization with Matplotlib and Seaborn
- Undo operations
- CSV export

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PyQt6

## Installation

Install the required dependencies:

`pip install -r requirements.txt`

Run the application:

`python main.py`
